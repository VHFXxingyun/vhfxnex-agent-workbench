## 二、当前作品盘点

### 已具备的主链路

- 登录、账号恢复、个人工作区、知识库、管理员控制台与 SQLite 持久化。
- 规划 Agent 提出候选路线；对话 Agent 回答交流和进度问题；工作台 Agent 通过结构化工具持续执行。
- 持久后台队列、SSE 流式状态、工具活动、执行取消、保存检查点、断线/切换工作区后的状态恢复。
- 工作区限时邀请共享：所有者、编辑者、只读成员权限隔离；成员可查看进度，撤权会取消该成员未完成的工作并清理附件。
- 联网搜索、知识库检索、参考图片和常见办公/代码文件作为上下文。
- 输出 DOCX、PDF、XLSX、PPTX、Markdown、ICS 和可下载代码项目 ZIP；静态 HTML 预览限制脚本、网络与外跳。
- 知识库优先使用本地缓存的中文 BGE 量化向量模型做语义检索，模型不可用时回退关键词检索；浏览器语音识别转写为文本，视频在浏览器本地抽取最多 6 帧，再发送给视觉模型。
- 代码项目生成后进行语法、JS/Vue 与 CSS/HTML 本地引用、源码导入和常见启动命令的 npm 依赖声明、清单静态检查，并尝试由独立复核 Agent 检查阻塞问题；平台不执行生成代码。
- 桌面、平板与手机布局；行动计划独立滚动；流程画布平移；成果默认折叠。

规划、对话、工作台和代码复核是同一 DeepSeek 服务下的职责分工与工具权限隔离；不要描述成多个独立模型互相辩论。知识库向量保存在 SQLite，本地模型文件缓存到 `data/models`；全新环境首次语义检索可能下载模型，失败会回退关键词检索。本机已用缓存模型验收向量推理、向量持久化和 `/api/plan` 混合召回。语音依赖浏览器 `SpeechRecognition` 实现；视频只抽帧、不传音轨，已在真实模型链路中通过一个合成蓝色视频帧样例，复杂自然画面及语音实时识别仍需人工复核。代码复核会产生额外 DeepSeek 用量，实时复核本轮未运行。

实时 DeepSeek 请求使用由账户 ID 与服务端 `SESSION_SECRET` 通过 HMAC 派生的稳定伪名 `user_id`，避免发送原始账户标识，并按应用账户隔离供应商 KV 缓存。相同账户的多个工作区共享同一伪名；轮换会话密钥会改变伪名并重置后续缓存分区。隔离可能减少不同账户间相同前缀的偶然复用、降低全局命中率，这是隐私与缓存复用的取舍；它不代表缓存命中承诺，也不会把跨账户请求合并计量。

## 四、部署风险

项目 README 将当前 SQLite 标为本地开发和单机部署方案。部署到无持久磁盘的容器平台时，重启可能丢失账号和工作区数据；部署方案未确认前，不应把本地可运行等同于公网可评审。

账户恢复采用一次性恢复码，不依赖邮件服务；生产环境还需配置有效的 `SESSION_SECRET`、管理员身份和服务端模型 Key。在线体验账号不得复用私人账户。
