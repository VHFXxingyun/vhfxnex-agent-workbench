# VHFXNEX 四项端到端验收

更新时间：2026-11-17

## 验收原则

这四项用于验证 VHFXNEX 能否把一次自然语言需求转成可检查、可下载的完整成果。实际项目必须由 VHFXNEX 的 Agent 生成和修订；验收人只提交初始要求、处理真正影响交付的关键选择，并检查最终文件，不逐步代替 Agent 指挥实现。

每项开始后，Agent 应在必要时先给出一次路线选择；路线确认后自主连续执行。纯进度询问应回答真实状态，不得重新规划或把未完成任务报告为完成。切换工作区后，原任务状态和成果应继续保存。最终验收以实际可下载文件为准，聊天中的完成声明不算交付。

测试过程中不为省 Token 缩短必要内容，也不以反复重跑代替修复。遇到余额、权限或工具阻塞时停止重复请求，明确报出原因并保留已有成果。复核发现内容缺陷时，将具体缺陷交回 VHFXNEX 修订；不得由验收人直接代写项目成果。

## 恢复执行后的首轮测试输入

这些是提交给 VHFXNEX 的真实用户需求，不包含验收清单。只在对应 Agent/额度可用时发送；附件需在 UI 中随消防场景上传。首轮如遇路线选择，只做一次关键选择，随后让 Agent 连续完成。

### 1. 消防活动策划

> 请按我上传的《棋兵连社团新生见面会活动策划书10.12.docx》格式，策划一场高校消防安全主题活动。我是定向培养学院的学生，想联合校内其他学院共同举办。保留文档现有标题、编号、顺序和格式，只修改正文内容，最后给我一份可直接执行、可下载的完整策划书。只有场地、审批等会影响实际可行性的关键信息缺失时，再一次性问我。

### 2. Windows 桌面项目关系管理系统

> 请为我做一个可下载运行的 Windows 桌面项目关系管理工具，用来管理多个软件项目及它们之间的关系。我需要管理项目、任务、负责人、状态、时间和依赖，能搜索筛选、查看进度与依赖关系，重启后数据还在。请自主选一条适合快速交付的技术路线，完成可运行版本并附启动说明；只把影响交付的关键选择交给我。

### 3. 蓝桥杯 C++ 本周学习安排

> 请给我安排本周剩余时间（2026 年 11 月 17 日至 22 日）的蓝桥杯 C++ 学习日程，精确到每个时段，包含课程学习、做题、复盘、吃饭和休息，内容从基础逐步推进到竞赛练习。请给我一份可以下载并照着执行的完整计划；我的个人课表信息不足时，请采用合理假设并注明，不要把小安排拆成问题逐项问我。

### 4. 丰川祥子桌面聊天窗口

> 请做一个 Windows 桌面聊天小工具：我能在窗口里发消息并进行多轮对话，暂时不需要桌宠立绘。角色是《BanG Dream!》中的丰川祥子，请依据可靠公开资料整理她的性格和说话风格，让聊天表现贴近角色；同时提供完整项目文件、运行说明和模型配置方式。遇到会影响能否运行或交付的关键选择时再问我。

## 每项结束前的统一复核

1. 确认 VHFXNEX 页面状态、Agent 回复和后台任务状态一致；进行一次进度询问并在切换工作区后确认运行状态仍可见。
2. 下载所有最终成果，检查文件确实存在、可打开、内容与要求一致；按场景核对结构、数据、时间和交付物。
3. 对代码项目在隔离目录按 README 启动，检查依赖、关键交互、数据持久化和测试；确认 GitHub 远端是验收后的版本。
4. 记录通过项、失败项、证据路径和实际阻塞原因。未满足任一必需交付时保持“未通过”，不以阶段成果或聊天文字代替。

## 恢复模型调用权限后的执行顺序

先把消防方案的现场事实与可行性复核闭环，并完成逐页目视检查；再完成 C++ 周计划；随后让 VHFXNEX 修复项目关系管理系统副本报告的编译问题、生成可下载包并通过本地验收，之后才按既有授权提交 GitHub；最后启动桌面聊天窗口。每个场景只在发现明确缺陷时将精确问题交回 Agent 修订，避免无目标重复执行。当前四项均未达到以上通过标准。本轮未调用 DeepSeek 或其他外部模型 API；C++、项目系统和桌宠的模型生成/修订仍待额度与授权恢复。
