## 比赛范围与产品匹配

赛事详情要求作品是 Web 应用，并强调 AI 应承担核心工作、体现工具/Agent 流程，而不是仅包装常规网页。VHFXNEX 的主线是目标规划、对话 Agent 的进度沟通与意图判断、工作台 Agent 的连续工具执行和多格式成果交付，形态是 Next.js Web 应用。报告应重点展示一条真实、可复核的任务闭环，并准确区分真实模型、演示模式、静态校验和未知事实。
