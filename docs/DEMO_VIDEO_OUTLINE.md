# VHFXNEX 参赛演示视频脚本（录制准备稿）

> 当前是可执行的录制准备稿，不代表视频已经录制，也不把样例当成真实模型结果。时长按 6 分 30 秒设计；分辨率与截止时间以报名平台最终通知为准。校内通知样例要求 5–8 分钟、1080p 普通话，正式录制前需再核实。

## 主场景

使用 `deliverables/demo-inputs/` 下的两份脱敏资料。旧版导出附件包含 Agent 运行记录和全部勾选完成的任务，其中联办、场地等仍是未确认计划；不要把那些勾选当成真实执行证据，也不要未经脱敏就把原文件放进公开视频或公开仓库。演示目标是：让 Agent 从活动要求和资料中识别约束，提出路线，接受一次方向选择，持续完成活动筹备工作，并交付真实可打开的成果。

### 演示输入

```text
请参考附件，策划一次冬日健康守护纸笔互动活动。演示口径是 20 名参与者（不含 5 名志愿者），活动总时长 75 分钟，4 个站点同时开放并由 4 组轮转，现金采购预算 0 元。地点暂按校内公共活动室规划，但可用时段、核定容量和实际物料都未确认；日期、联办单位也未确定。请先给出三条有实质区别的执行路线和推荐理由，我确认方向后再执行。普通细节按合理默认值连续完成，不要逐项问我；安全、场地容量或健康知识来源若无法可靠处理，再提出一个关键问题。不要声称已联系、预订、采购或完成任何现场任务。
```

录制时若决定隐去校内名称，可把“定向培养学院”和“大学院客厅”替换成已脱敏称呼；同一视频里保持称呼一致。不要在公开视频展示个人姓名、手机号、账号邮件、真实 API 用量账户或密钥。

## 录制前准备清单

1. 使用实时 AI 模式完成一次端到端彩排；不把演示模式样例剪成真实模型表现。
2. 确认附件版本已脱敏，目标、路线选择、聊天指令与最终文档使用同一组真实数据。
3. 先彩排一次下载并打开成果；若预算、PDF、搜索来源或某项工具没有实际生成，就从台词和画面中删掉该项。
4. 只展示确实发生的工具调用；不得伪造“正在运行”动画、搜索来源、耗时、用量、预算或完成进度。
5. 如果要展示联网搜索，现场确认真实结果来源已随执行保存，点击来源可打开；否则不把搜索列为主场景证据。
6. 录制时使用 100% 缩放，检查完整工作台和文字可读性；输出至少 1080p，隐藏浏览器密码栏、个人信息、通知和开发者错误覆盖层。
7. 录屏后从头检查声音、光标、裁切、字幕、文件打开结果和敏感信息；保留原始录屏和对应成果文件。

## 不应在视频中声称

- 尚未部署公网就说评委可以在线访问；尚未真实试用就宣称用户效率提升或准确率。
- 把同一模型服务下的职责分工说成多个独立模型组成的自治团队。
- 把静态源码校验说成代码已安全运行，或把静态网页预览说成交互项目已部署。
- 把本地自动化 smoke 结果说成真实用户研究或真实模型质量评测。
- 展示或念出 `.env.local`、API Key、账户密钥、私人资料及未经授权的活动信息。
