# VHFXNEX 主演示验收表｜冬日活动场景

## 推荐演示输入

先上传同目录中的两份脱敏参考资料，再提交：

```text
请参考附件，策划一次冬日健康守护纸笔互动活动。演示口径是 20 名参与者（不含 5 名志愿者），活动总时长 75 分钟，4 个站点同时开放并由 4 组轮转，现金采购预算 0 元。地点暂按校内公共活动室规划，但可用时段、核定容量和实际物料都未确认；日期、联办单位也未确定。请先给出三条有实质区别的执行路线和推荐理由，我确认方向后再执行。普通细节按合理默认值连续完成，不要逐项问我；安全、场地容量或健康知识来源若无法可靠处理，再提出一个关键问题。不要声称已联系、预订、采购或完成任何现场任务。
```

路线确认后，只发一条连续执行指令：

```text
按我选定的路线连续完成筹备方案、75 分钟相对时间表、4 组轮转安排、至少 5 名志愿者岗位、逐项物料盘点表、四个站点规则和风险处置。保留日期、联办单位、场地可用时段/容量、实际库存为待确认；为涉及健康结论的题卡查找可靠来源，找不到就改成非诊疗类内容。生成一份可编辑的活动方案文件，并在工作区显示真实的任务进度和交付成果。普通步骤自动推进，只有影响安全或整体路线的未决事项才问我。
```

## 结果判定

| 核对项     | 通过标准                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------- |
| 路线选择   | 首轮有 3 条内容不同的路线，推荐有理由；用户确认后不再逐项确认普通细节                           |
| 人数与场地 | 明确 20 名参与者不含 5 名志愿者；总到场人数按 25 人核算；核定容量未提供时保留检查，不写成已确认 |
| 游戏运行   | 有 4 组、4 个同时开放站点、每站 1 位主持；每组走完 4 站，轮转和换场时间合计不超过 75 分钟       |
| 人员安排   | 至少 5 名志愿者职责互不冲突；6 人时明确额外岗位；不要求同时在两个位置工作                       |
| 预算与物料 | 现金采购为 0；区分“建议物料”和“盘点后可用物料”，未盘点的来源仍待确认                            |
| 健康与包容 | 健康结论有可靠来源或被替换；游戏不诊断、不淘汰、不强迫运动，包含可选坐姿参与                    |
| 真实性     | 日期、场地、联办单位、人员和现场执行状态均不捏造；所有规划任务初始保持待办                      |
| 可交付物   | 工作区里确实存在可打开、可下载的活动方案；文件内容与聊天、任务和时间表一致                      |
| Agent 推进 | 用户一条执行指令后连续执行；进度问答能依据已保存状态回答，不会重复启动一轮工作                  |

## 录屏前人工复核

- 实时运行至少一次完整彩排，确认路线、工具事件、任务状态和下载文件都来自本次真实执行。
- 打开最终文件核对人数、时长、岗位、物料、健康来源和待确认字段；仅凭“已生成”提示不算通过。
- 拍摄、上传或公开资料前复核活动称呼、位置、参与者影像、浏览器账号信息和模型用量截图。
- 若联网搜索或某种 Office 导出本次没有成功，就不要在视频中把它作为已经演示的能力。
