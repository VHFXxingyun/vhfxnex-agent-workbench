# 冬日健康守护活动｜需求简报

> 脱敏演示资料，依据团队提供的旧活动草案重新整理。此文件只用于产品演示，不表示活动已获批准、已举办、场地已预订或联办单位已确认。旧草案中的 Agent 运行记录和任务勾选不作为真实执行凭证。

## 已明确的演示约束

- 主题：冬日健康守护，以轻松、低门槛的纸笔互动为主。
- 规模：20 名活动参与者，**不含** 5 名志愿者；第 6 名志愿者可作为机动支持。该人数口径是本次演示的明确设定。
- 时长：活动总时长 75 分钟，包含签到、暖场、游戏轮转、收尾和反馈。
- 预算：现金采购预算为 0 元；优先使用经盘点确认可借用的物品、回收材料和手写卡片。未盘点前不得声称物料“现有”。
- 玩法：4 个简单站点；每组都应完成全部 4 个站点；不淘汰、不以体能或健康状况评分。
- 资料：可参考同目录的《纸笔游戏设计参考》；旧草案中的个人信息、旧 Agent 状态和完成勾选不属于本演示输入。

## 尚未确认，不能编造

- 日期、开始时间和活动是否获批。
- 联办单位名称、对接人及其承诺。
- 校内公共活动室的可用时段、实际安全容量、通道和无障碍条件。
- 学院实际可借物料、志愿者姓名及最终岗位。
- 健康知识题卡引用的可靠来源。

## 执行边界

- 可以生成筹备方案、相对时间表、任务清单、岗位表、物料盘点表和待确认事项。
- 不得代替团队联系学院、预订场地、确认人员、采购、发通知或声称活动已发生。
- 未核实场地安全容量前，方案必须保留容量核对任务；若容量不足，应减少人数或更换场地后再执行。
- 若题卡出现医学或健康结论，先通过可靠机构资料核验并附来源；未核验的说法不得写成事实或用于判断输赢。可以改用不涉及诊断的生活习惯题。
